# agency - Nexora Digital Agency

A modern, high-performance digital agency website built with React, Vite, Tailwind CSS, and Framer Motion.

## Features
- Modern Glassmorphism & Cyberpunk-inspired UI
- Dynamic Services, Portfolio, Skills, and Team showcases
- Interactive animations with Framer Motion & Lucide Icons
- Fully responsive design

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
